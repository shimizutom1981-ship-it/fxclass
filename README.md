FxClass（骨折Navi）
イラスト・シェイプをタップしていくだけで、AO/OTAコードおよび主要な臨床分類（Garden、Schatzker、Tileなど）へ最短ステップで到達できる、整形外科医向けの骨折分類判定・カルテ支援Webアプリケーションです。

主な特徴
直感的なツリー選択（ドリルダウンUI）

解剖学的部位 ➔ 骨折領域 ➔ X線所見・形態の順にタップするだけで、目的の分類に即座に到達します。

主要臨床分類を網羅

長管骨のAO/OTA分類に加え、骨盤輪（Tile分類）、寛骨臼（Judet-Letournel分類）、大腿骨頚部（Garden分類）、脛骨近位端（Schatzker分類）など、術式決定に直結する分類をカバー。

ワンタップでカルテ出力

判定結果、病態の要点、代表的な術式指針を整形したテキストとして、ワンタップでクリップボードにコピー可能。電子カルテ、紹介状、カンファレンス用サマリーへの転記を効率化します。

ゼロインストール & 完全オフライン動作

外部ライブラリ（React/Vue等）への依存がない単一のHTMLファイル構成。ネット環境のない病棟や手術室でもスタンドアロンで動作します。

動作環境
モダンブラウザ（Safari, Google Chrome, Microsoft Edge, Firefox, Braveなど）

スマートフォン、タブレット、PCの全デバイス対応（レスポンシブ表示）

使い方
1. 起動方法
ダウンロードした fracture_classifier.html をブラウザで直接開きます。

2. スマホでアプリ化（PWA / ホーム画面追加）
iOS (Safari): 画面下部の「共有」アイコン ➔ 「ホーム画面に追加」

Android (Chrome): 右上のメニューアイコン ➔ 「ホーム画面に追加」または「アプリをインストール」

ホーム画面から全画面表示（アドレスバー非表示）のネイティブアプリ感覚で利用できます。

3. 操作手順
トップ画面から対象の骨（例: 大腿骨、骨盤、脛骨）をタップ。

骨折部位やX線所見に応じたイラスト・項目を選択。

判定画面に表示されたコードと臨床指針を確認。

「カルテ・サマリー用にコピー」をタップして電子カルテ等に貼り付け。

データ構造・拡張について
DATA_TREE オブジェクトを編集することで、新たな骨折型や分類（上腕骨近位端のNeer分類、足関節のLauge-Hansen分類など）を簡単に追加できます。
